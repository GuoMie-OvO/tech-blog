iOS AI Agent
探索问题

云端 Agent 难以直接使用手机的屏幕、应用与手势。我希望验证：执行环境留在手机上，能否持续完成复杂任务。

架构选择

Swift 原生壳 + WKWebView 承载界面与原生桥接；Python Harness 负责 Agent Loop、任务路由与工具调用。远程模型 API 负责推理，本地负责执行。

一次可量化的改进

工具按用途注册、按需挂载；本地规则完成路由，MCP 不可用时回退到内置工具。在单次设备操作回归中，工具 Schema 开销降低约 54%。

端侧运行的是 Harness 与工具执行环境，并未在手机上部署大模型。
