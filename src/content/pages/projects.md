## iOS AI Agent

**个人项目 · AI 工程 / 移动端**

探索手机上的 Agent 工作环境：iOS 应用承载聊天、工作界面与原生能力，Python Harness 组织任务和工具执行，远程模型 API 负责推理。

重点关注工具按需挂载、上下文管理、异常回退与执行状态。采用 MCP 开放标准接入工具，自有实现与第三方组件的边界在原作品集中分别说明。

这是移动端的任务编排与工具执行环境；大模型推理由远程 API 提供。

## 澄页 Clearleaf

**个人项目 · 阅读应用**

围绕本地电子书阅读展开的个人应用，强调本地优先的使用方式。已提供 Windows 桌面应用。

Windows 版本采用 Electron 与 React。支持导入本地图书、整理书架，以及阅读背景、字体与排版设置；文字类图书支持连续滚动，也可以在阅读时自动隐藏工具栏。

桌面版本的文件选择器包含 EPUB、TXT、PDF 等格式，不同格式的实际兼容性以当前版本为准。

安装包尚未提供公开下载入口，后续会随公开版本补充。

## Android 连点器

**个人项目 · Android / 自动化工具**

将重复的屏幕操作组织成可保存的脚本，支持点击、长按、滑动、执行间隔与循环次数设置。

通过悬浮控制器管理执行状态，并以可拖动点位配置操作位置。应用需要用户主动开启悬浮窗与无障碍手势权限。

已提供 Android APK。本页介绍依据当前安装包中的界面与功能元数据，后续公开版本会补充演示与下载入口。
