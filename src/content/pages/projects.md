## iOS AI Agent

**个人项目 · AI 工程 / 移动端**

探索手机上的 Agent 工作环境：Swift 原生壳与 WKWebView 承载聊天、工作界面和原生能力，自研 Python Harness 组织 Agent Loop、任务路由、工具调用与上下文管理，远程模型 API 负责推理。

重点关注工具按需挂载、Memory / Skills、上下文压缩、断点续跑与异常回退。采用 MCP 开放标准接入工具，系统控制能力复用第三方组件，自有实现与开源依赖分别说明。

真机验证中，曾修复工具漏挂、旧工具路径误用与工具协议文本泄漏，并压缩工具描述的冗余。作品集记录的一次设备操作回归中，工具 Schema 开销从 7,428 降至 3,419 tokens，约减少 54%；这是单次回归结果，不代表所有任务的普遍提升。

手机本地运行的是任务编排与工具执行环境，大模型推理由远程 API 提供。

## Android 开源连点器 · Liquid Glass Tapper

**个人项目 · Android / 自动化工具 / 开源**

把重复操作变成可控的动作。面向 Android 新手，将权限准备、动作编辑、屏幕点位和悬浮执行组织成完整路径。

**使用路径：开启权限 → 编辑动作 → 悬浮执行。**

- **动作编排**：点击、长按、滑动；顺序执行与多点同时点击。支持高速重复与秒级间隔，脚本可新建、编辑和复用预设。
- **直接操控**：悬浮控制器与屏幕点位可拖动；录屏隐藏模式收起控制器和点位，长按实体音量键恢复入口。
- **新手引导**：解释悬浮窗与无障碍权限的用途，为常见厂商系统提供兼容设置提示。
- **视觉与交互**：液态玻璃底栏、可横滑的分段选择与弹性反馈，支持跟随系统、浅色和深黑主题。

Kotlin / Jetpack Compose 构建界面，无障碍服务执行用户主动启动的手势，Backdrop 提供玻璃渲染，Coroutines 组织异步任务。脚本和设置保存在本地，无账号和云端上传。

[查看 GitHub 源码与构建说明 ↗](https://github.com/GuoMie-OvO/liquid-glass-tapper)

项目采用 Apache 2.0 许可证，要求 Android 10 及以上。实际执行依赖用户授权与厂商系统行为，当前版本与使用说明以仓库为准。

## 澄页 Clearleaf

**个人项目 · 阅读应用**

**只读你的世界。** 独立开发的本地桌面电子书阅读器，将导入、书库搜索、阅读设置、进度和批注连接起来，让用户打开自己的文件，回到上次阅读的位置。

![澄页实际书库空状态：本地图书导入、搜索、网格和列表切换](/uploads/clearleaf-library.png)

*实际应用界面，展示空书库；未包含个人图书与阅读数据。*

- **本地书库**：按书名、作者或格式搜索，提供网格与列表视图。
- **多格式入口**：EPUB、TXT、PDF、MOBI、AZW3、FB2、CBZ、CBR、HTML 和 Markdown，通过不同路径解析内容。
- **阅读环境**：纸张、护眼与夜间等主题，字体、字号、行距、页边距和亮度可调。
- **定位与记录**：目录、全文搜索、书签、划线批注、笔记与阅读进度；记录保存在本机。
- **连续阅读**：翻页、滚动、键盘操作与全屏，持续保存阅读设置和书库状态。

Electron 处理本地文件与桌面窗口，React 组织书库和阅读界面，阅读层复用 Foliate 等开源能力。

当前已提供 Windows 桌面应用。格式入口不代表所有加密文件与复杂排版均已逐一兼容；未加入尚未验证的使用量或性能收益。公开下载入口将在后续版本补充。
