龙虎榜

买入与卖出双表并列，连接营业部、席位与资金结构；事实榜单与战法筛选分开。

题材与概念

从排行、涨停家数与资金表现进入关联个股，连接板块判断与个股分析。

综合打分

结合综合评分、资金流和技术维度筛选，提供搜索、交易日期及历史优选。

舆情与个股下钻

从市场趋势和行业信息进入个股详情，查看情感构成、来源和相关原文。

智能问答与连续浏览

接入模型服务，支持多模型选择、流式输出、多轮会话与停止生成。历史会话保存在当前浏览器，附件与网页通过侧栏预览。舆情页保留挂载状态，缓存并合并请求，通过快照版本检查触发后台更新，减少切页时的整页等待。

案例二 · 金融舆情系统

04 / 10

让研判连接到具体内容与具体对象

金融信息来自文章和视频，一份报道可能涉及多只股票与多个行业。系统将内容接入、特征整理、文章情感、逐股及行业研判、统计接口与展示串成完整链路，回答「对哪只股票、哪个行业有什么影响」，并保留来源与判断依据。

文章与视频，走进同一条分析链路

01接入与整理

只读获取上游内容，提取原文、来源链接、关键词、实体、股票和行业关联，写入本地数据库。

02去重与规范化

聚合统计使用规范化标题、内容哈希与时间分组，减少转载对报道量和榜单的重复放大。

03视频转文字

审核金融相关性，通过后提取音轨并转写；保留来源，将原记录升级为视频，避免重复入库。

04对象级研判

形成文章情感，再对股票与行业分析影响、相关性和理由；符合条件的短文复用联合结果。

05统计与供给

结果存入本地 PostgreSQL，经只读 API 供市场大盘、个股详情、行业统计和下游工具消费。

三个视角，服务不同的研究问题

市场：整体发生什么？

查看去重报道量、已研判覆盖率、情感构成、市场情绪、趋势、热门股票、来源与最新报道。

行业：影响落在哪里？

独立行业研判、行业排行与相关报道，不把整篇文章的情感标签直接当作行业结论。

个股：与它有什么关系？

结合逐股研判、情感构成、热词、报道占比和来源，打开相关原文检查依据。

清晰口径，让结论可用

趋势同时展示报道量与 3 日滚动净情绪。先汇总窗口内利好与利空，再计算差值比例；没有有效样本时保留缺失，避免把「无数据」写成「情绪中性」。当日值、区间值与累计快照分别使用；情感构成以已研判报道为分母，累计点击和播放保留来源口径。

可解释的正向候选

结合逐股样本量、平滑比例和稳健排序呈现候选，展示实际统计区间与少样本提示。

持续更新与恢复

缓存和快照版本保持阅读连续；视频采用持久任务队列，临时失败重试，中断任务重启后入队。

部署形态：前端与数据服务可在客户环境部署，推理可选本机 Ollama 或远程兼容接口。使用远程服务时会发送分析文本，本地存储不等于全部文本始终不出网。

最近 90 日滚动处理为运营策略，不写成代码硬性自动清理保证。上游读取与本地结果写入分离；Worker 保留处理状态、模型版本、理由与失败信息，以只读 API 供给下游。

为什么做端侧

云端 Agent 难以直接使用手机的屏幕、应用与手势。我希望验证：将 Harness 与工具执行环境留在手机上，能否持续完成复杂任务。推理由远程模型 API 完成。

四层架构

iOS App 前端

Swift 原生壳 + WKWebView。承载聊天与工作界面、原生能力桥接。

Python Harness（核心）

Agent Loop、任务路由、工具调用、上下文与 Memory / Skills / 压缩 / 断点。常驻后台，经本地 HTTP 与前端通信。

模型 API

远程大模型负责推理、生成与工具调用决策。手机本地跑的是 Harness 与工具执行环境，不部署大模型。

工具执行层

内置工具 + MCP + iOS 控制工具：读写文件、代码检索、屏幕识别、语义点击、启动 App 等。前端与 Python 后端分离——App 承载界面与原生能力，Python 负责任务执行与编排。

案例三 · 工具链与真机验证
调度、回退，与一次可量化的改进
07 / 10

工具链怎么组织

  • 工具按用途注册；Router 与工具选择器采用本地规则，不额外消耗一次模型调用。
  • 按需挂载：只把当前任务需要的工具放进上下文，而不是一次塞入全部工具。
  • 集成开源 iOS MCP 服务，接入其 46 个系统控制工具，工具总规模 70 个。
  • MCP 不可用时自动回退到内置工具，避免整条链路中断。

真机排障

  • 修掉工具漏挂与旧工具路径误用——模型请求了并未挂载的工具，导致执行中断。
  • 修掉工具协议文本泄漏——工具调用协议被当成回答内容输出给用户。
  • 压缩上下文冗余，并为执行失败设计异常回退。

从本地文件，到连续的阅读体验

围绕阅读任务，组织核心能力

多格式与本地书库

入口覆盖 EPUB、TXT、PDF、MOBI、AZW3、FB2、漫画压缩包、HTML 和 Markdown，通过不同路径解析内容。

桌面交付
